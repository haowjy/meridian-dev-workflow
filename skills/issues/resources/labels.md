# Issue Labels

| Label | Use for |
|---|---|
| `bug` | A defect found during the work |
| `unexpected` | Surprising behavior worth investigating |
| `backlog` | Work needed but out of current scope |
| `deferred` | Deferred from the current work |
| `review-finding` | From a code review, not blocking |
| `decision-needed` | Waits on the human's decision |
| `tech-debt` | Structure to fix later |
| `enhancement` | A new feature or an improvement |
| `blocked` | Can't proceed until something outside it is resolved |
| `work:<slug>` | Links the issue to its active work item, with the item's slug |

Create a label the repository lacks with `gh label create <name> --description "..."`.
