# Typography

For a new type system, aim for body lines of 65-75 characters, clear
contrast in size and weight, and few families. Pair fonts that contrast, or
use one family in several weights; two similar fonts look like a mistake.
Use all-caps body copy, very large headings, or tight tracking only where
they serve the brief and stay readable.

Set `text-wrap: balance` on h1-h3 and `text-wrap: pretty` on long prose.
